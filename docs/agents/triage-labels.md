# 分类标签

技能使用五种标准分类角色。本文件将这些角色映射到本仓库 Issue tracker 中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库 tracker 中的标签 | 含义                         |
| -------------------------- | ---------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`         | 维护者需要评估此 Issue       |
| `needs-info`               | `needs-info`           | 等待报告者补充更多信息       |
| `ready-for-agent`          | `ready-for-agent`      | 已充分定义，可供 AFK agent 接手 |
| `ready-for-human`          | `ready-for-human`      | 需要人工实现                 |
| `wontfix`                  | `wontfix`              | 不处理                       |

当技能提到某个角色时（例如"应用 AFK-ready 分类标签"），请使用本表对应的标签字符串。

如需调整，请编辑右侧列以匹配你实际使用的词汇。
